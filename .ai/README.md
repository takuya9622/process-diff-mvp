# AI向け指示

このディレクトリは、コーディングエージェント間で共有する指示の正本です。
リポジトリルートに置く各エージェント固有のファイルは、共通ルールと必要に応じた
エージェント固有の補足を読み込むための薄いアダプターとして扱います。

## 参照順

1. `.ai/rules.md`を読む。
2. 使用中のエージェントに対応する`.ai/agents/<agent>.md`があれば読む。
3. タスク固有のプロジェクト文書は必要なものだけ読む。

`docs/`配下の文書を作成または更新する場合は、先に`docs/README.md`の記述ルールを
確認します。

現在のユーザーによる明示的な指示と、実行環境から与えられる指示は常に優先します。
エージェント固有の補足には実行方法の違いを記載できますが、共通のプロジェクトルールを
弱めたり、重複して記載したりしてはいけません。

## ファイル

- `.ai/rules.md`: 共通のプロジェクトルールとPublicリポジトリの情報境界。
- `.ai/agents/codex.md`: Codex固有のアダプター情報。
- `.ai/agents/claude.md`: Claude Code固有のアダプター情報。
- `AGENTS.md`: Codexが参照する入口。
- `CLAUDE.md`: Claude Codeが参照する入口。

## メンテナンス

- 共通の振る舞いは`.ai/rules.md`だけを変更する。
- エージェント固有の実行方法の違いは`.ai/agents/<agent>.md`に記載する。
- ルートのアダプターファイルは、参照順と読み込み指示だけに限定する。
- 人間が参照する文書とエージェント向けルールは、原則として日本語で記載する。
- 別のエージェントを追加するときは、そのエージェントに必要な最小限の入口ファイルを
  作成し、このディレクトリを参照させる。
